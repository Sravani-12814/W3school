# 🔗 HTML Hyperlink Example

## 📌 Project Description

This project is a simple HTML webpage that demonstrates how to create hyperlinks using the **`<a>` (anchor)** tag and the **`href`** attribute. When users click the hyperlink, they are redirected to the specified website. This project is designed for beginners who are learning the basics of HTML and how links work in web pages.

---

## 🎯 Objectives

* Learn how to create hyperlinks in HTML.
* Understand the purpose of the `href` attribute.
* Practice basic HTML page structure.
* Navigate users to external websites.

---

## ✨ Features

* Simple HTML webpage
* Uses the `<a>` tag
* Demonstrates the `href` attribute
* Opens an external website
* Beginner-friendly example

## 🚀 How to Run

1. Download the project.
2. Open `index.html` in any web browser.
3. Click the **"Visit W3Schools"** link.
4. The browser will navigate to the W3Schools website.
